## 🚀 About The Project

**F1 Library Management System** is a modern and responsive web application designed to manage books, users, and library operations efficiently.

This project provides:

- 📖 Book Management
- 👨‍🎓 Student Portal
- 👨‍💼 Employee Portal
- 🛡️ Admin Dashboard
- 🔐 Authentication System
- 🎨 Modern UI/UX
- ⚡ Fast Performance
- 📱 Mobile Responsive Design

# ⚙️ Installation Guide

## 1️⃣ Clone The Repository

```bash
git clone https://github.com/your-username/f1-library-system.git
```

---

## 2️⃣ Navigate To Project Folder

```bash
cd f1-library-system
```

---

## 3️⃣ Install Dependencies

```bash
npm install
```

---

## 4️⃣ Start Development Server

```bash
npm run dev
```
